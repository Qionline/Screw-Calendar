# Screw Calendar 用户指南

## 下载和首次启动

1. 从项目的 [GitHub Releases](https://github.com/Qionline/Screw-Calendar/releases) 下载 Windows x64 压缩包和同名 `.sha256` 文件。
2. 计算压缩包的 SHA-256 并与发布页文件比较：

   ```powershell
   Get-FileHash .\ScrewCalendar-*-win-x64.zip -Algorithm SHA256
   ```

3. 解压到具有写入权限的普通文件夹，运行 `ScrewCalendar.exe`。
4. 程序启动后自动定位到今天，并把今天放在第二个日期行。程序关闭窗口后仍可驻留在系统托盘。

Screw Calendar 是免安装、自包含程序，不要求另行安装 .NET Runtime。当前支持 Windows 10/11 x64。

## 日历操作

- 工具栏左侧显示当前日期和星期。
- 使用左右箭头按月翻页；选择“回到今天”可恢复今天的位置。
- 双击日期方格可编辑该日的 Markdown 待办。
- 设置中的“日期行数”可在 5～10 行之间调整。窗口保持固定比例整体缩放，不提供日历滚动。
- 月份跨行时，月份标签显示在当月 1 日上方。
- 日历显示二十四节气以及 2025～2026 年中国法定节假日与调休；其他年份不会标注法定节假日或调休。

## 外观

设置中提供以下选项：

- Windows 11、极简和桌面挂件三种样式。
- 浅色和深色模式。
- 蓝色、青绿色、紫色和橙色主题色。
- 整体透明度。切换样式时会应用该样式的默认透明度。
- 今天高亮和周末视觉区分由所选样式及主题色共同决定。

桌面挂件样式的窗口背景透明，桌面壁纸会透过日期方格之间的区域显示。

## Markdown 待办

底部待办区域包含常驻待办和今日待办。日期方格中的内容与对应日期的 Markdown 文档使用同一份本机数据。

编辑器支持：

- 普通模式和 Markdown 源码模式。
- 一级、二级、三级标题。
- 无序列表和任务列表。
- 勾选或取消任务。
- 粘贴或拖入 PNG、JPEG 等受支持图片。

图片会转换为 PNG，并按内容 SHA-256 保存到本机 `assets` 目录。删除原始图片不会影响已经归档的待办图片；相同内容只保存一份。

## 窗口和托盘

- “始终置顶”使日历位于普通窗口上方；关闭后日历保持在普通窗口下方。全屏应用仍可覆盖日历。
- “锁定位置和大小”只禁止拖动和缩放，不会锁定日历内容。
- “开机启动”在当前 Windows 用户登录时启动日历。
- 关闭主窗口后可从系统托盘重新显示，托盘菜单也可以切换置顶、锁定和开机启动。
- 程序记住显示器、位置和大小。原显示器断开后，窗口会移回当前可见屏幕。
- 程序只允许一个实例运行。

## 数据、备份与恢复

数据仅保存在当前 Windows 用户的本机目录：

```text
%LocalAppData%\ScrewCalendar\data\calendar.json
```

每次成功保存时，程序维护最近一份有效备份 `calendar.json.bak`。主文件损坏时会尝试从备份恢复，错误信息写入 `%LocalAppData%\ScrewCalendar\logs\app.log`。

设置中的“导出 JSON”包含 Markdown 和应用设置，但不包含图片文件。完整迁移步骤：

1. 在旧电脑导出 JSON。
2. 退出旧电脑上的 Screw Calendar。
3. 复制 `%LocalAppData%\ScrewCalendar\data\assets` 文件夹。
4. 在新电脑启动一次应用，然后退出。
5. 把 `assets` 复制到新电脑的相同数据目录。
6. 启动应用并导入 JSON。

导入会替换当前本机数据。执行导入前建议保存导出文件和 `assets` 的副本。

## 升级和卸载

升级时退出应用，将新版本解压到新的目录后运行即可。用户数据位于 `%LocalAppData%`，不会因替换程序目录而丢失。

卸载时先从托盘退出，并在设置中关闭开机启动，然后删除程序目录。若也要删除全部待办、图片、设置和日志，再删除：

```text
%LocalAppData%\ScrewCalendar
```

删除数据目录无法撤销，请先完成备份。
