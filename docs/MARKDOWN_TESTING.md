# Markdown 回归验收

本文维护当前公共编辑器的验收步骤；重复提醒另见 [REPEAT_TESTING.md](REPEAT_TESTING.md)，正式发布见 [RELEASING.md](RELEASING.md)。不再按历史开发阶段维护多份检查表。

## 编辑与保存

在日期弹窗、底部常驻、底部今日区域分别检查：

1. 默认当前物理行显示源码，其他行保持排版；自动换行仍属于同一源码行。跨行选区涉及的行展开，离开后恢复；标题展开仍保留字号。
2. 工具栏顺序为 `MD`、`H`、`B`、列表、任务；日期编辑额外有 `Rp`，常驻区没有。按钮保持 30×30，窄栏换行，不被挤压；没有 T、预览或图片按钮。`H` 默认应用 H2。
3. 点击 B 或 Ctrl+B 为选中文字切换 `**text**`，无选区时插入成对标记并把光标放在中间；阅读时显示实际加粗。
4. 反复切换 MD 完整源码与当前行编辑，检查原文、空白、选区、滚动位置及撤销历史；Ctrl+A、跨行拖选、Shift+方向键、剪切、替换、撤销和重做保持正常。
5. 底部 `×` 和 Ctrl+S 保存，Esc 取消；弹窗保存按钮保存，取消和 `×` 放弃草稿。另一栏的独立草稿保留；清空今日后恢复常驻单栏。
6. 编辑今日弹窗时，底部同步预览；取消后恢复保存内容。日期 A 编辑后打开 B，先保存 A 再打开 B；重复打开同一天只激活已有窗口。磁盘不可写时保留原窗口与草稿并停止切换。

## 排版与交互

1. 分别测试首行 `---`、紧接正文的 `---`、前有空行的 `---`：阅读时均为横线，浅色主题用深灰、深色主题用浅灰，普通正文与 repeat 区块内均清晰；代码块中保持原样。未支持的结构保留源码。
2. 普通、已完成、加粗和嵌套任务的复选框与文字垂直居中，上下各 2px 间距；长任务只与首行对齐。阅读中直接勾选并保存，编辑中点击非当前行的任务框则进入源码，代码块中的任务不可勾选。
3. 列表／任务末尾 Enter 继续相同类型，已完成任务的新行默认未完成；空列表项 Enter 退出，代码块不自动续写列表。
4. 阅读复制得到可见文本，编辑复制保留 Markdown。链接、勾选、拖选不得误触发编辑；源码和可见文本的位置映射保持正确。
5. 测试 `[2026 鉴赏家新品节](https://act.steamchina.com/2026showcase)` 位于行末、后接空格、前后接正文的情况；仅文字显示手形和网址提示并可点击。窄栏自动换行、长文滚动后，行尾空白也不得触发链接。
6. 粘贴截图、粘贴图片文件、拖入图片：源码引用归档后的 `assets/...`，删除原图不影响显示，图片按窄栏等比缩小。删除源码引用后图片消失；插入后滚动到新图片。代码块和图片行在编辑中保留源码，阅读时排版。

## 人工体验与界面回归

- 连续中文输入法组合、选词、快速跨行拖选、长文滚动及切换模式，检查跳光标、吞字、闪烁与卡顿；自动测试不能替代真实输入法和鼠标体验。
- 检查经典／极简／紧凑、深浅主题、主题色、透明度及中英文；日历列对齐和固定尺寸保持不变，待办高度与日历缩放独立。
- 非置顶桌面模式可进入内联编辑并输入；保存／取消后恢复桌面层级，主窗口不进入 Alt+Tab，Win+D 和托盘显示隐藏正常。

## 自动验证与测试包

使用仓库 SDK 8.0.425，在根目录运行：

```powershell
dotnet restore ScrewCalendar.sln --configfile NuGet.Config --locked-mode
dotnet run --project tests/ScrewCalendar.Tests/ScrewCalendar.Tests.csproj -c Release --no-restore --disable-build-servers
dotnet format ScrewCalendar.sln --verify-no-changes --no-restore --verbosity minimal
dotnet publish ScrewCalendar.csproj -c Release --no-restore --disable-build-servers -o artifacts/publish
```

设置 `SCREW_MARKDOWN_QA_DIR` 为输出目录，可保存原生 WPF 渲染截图。测试使用独立临时数据，不操作正式用户存档。查看测试包前先从托盘退出旧程序，避免单实例逻辑仍显示旧版本。
