# Markdown 第一期验收

本文记录第一期 Markdown 的本地验收步骤；当前行源码编辑等后续行为见 [第二期验收](MARKDOWN_PHASE2_TASK1_TESTING.md)。测试时先通过设置导出 JSON 备份；图片单独保存在本机数据目录的 `assets` 中。

## 打包

使用仓库发布 SDK（.NET 8.0.425），直接执行 `dotnet publish ScrewCalendar.csproj -c Release -o artifacts/publish` 检查本地效果。正式发布和标签推送按 [RELEASING.md](RELEASING.md) 执行。

## 核心交互

1. 日期弹窗中粘贴下方样例，编辑时应完整显示源码。点击右上角“预览”，检查排版；再切回“编辑源码”，字符和空白应完全一致。
2. 在源码中增删文字，反复预览后执行 Ctrl+Z／Ctrl+Y，撤销和重做仍正确；跨行拖选、Ctrl+A、复制、剪切和替换也应正常。
   - 分别测试首行 `---`、紧接正文的 `---`、前面有空行的 `---`；阅读时都应显示横线，代码块中的同样符号保持原样。
   - 选中文字点击 B 或 Ctrl+B，应生成 `**text**` 并在预览中加粗，再次点击可取消；没有选区时光标应位于成对标记中间。
   - 比较弹窗与底部的 T、H、B、列表、任务按钮，均应为 30×30 正方形；缩窄底部栏后应换行而不压扁按钮。
3. 在底部常驻／今日正文单击进入编辑，保存后回到排版。Esc 或取消按钮放弃草稿，Ctrl+S 保存；另一栏内容保留。
4. 在阅读状态拖选并复制，应得到可见文本；单击链接打开浏览器，勾选任务直接保存，不应误进入源码编辑。代码块里的任务符号不可勾选。
   - 检查普通、已完成、加粗和嵌套任务的复选框与文字垂直居中；长任务换行后，复选框仍与第一行对齐。
5. 编辑今日弹窗时，底部应实时显示草稿；取消／关闭后恢复原文。此时在常驻区输入的独立草稿应保留。
6. 日期 A 输入后打开 B：A 自动保存，B 打开；重复打开同一天不重复创建窗口。磁盘不可写时，应保留窗口与草稿，不继续切换。

## 输入、图片与布局

1. 连续使用中文输入法输入长句并选词，检查是否跳光标、吞字、闪烁或明显卡顿。
2. 列表／任务行末按 Enter 继续列表，已完成任务的新行默认未完成；空列表项按 Enter 退出；代码块内按 Enter 不自动添加列表。
3. 粘贴截图、复制图片文件后粘贴、拖入图片；源码应引用归档路径，预览应显示图片，窄窗口按宽度缩小。删除源图片文件后预览仍可用；源码删除引用后图片消失。
4. 在长文档中滚动到中间，切换预览／编辑，检查滚动位置和点击落点；缩窄窗口后检查长链接、长代码行和图片。
5. 检查经典／极简／紧凑、浅色／深色、主题色、透明度及中英文；日历方块与星期栏对齐不变，待办高度不随日历缩放改变。
6. 非置顶桌面模式中进入内联编辑后应能输入，保存／取消后恢复桌面层级；主窗口仍不进入 Alt+Tab，Win+D 和托盘显示隐藏行为保持正常。

## 可复制样例

````markdown
# 一级标题
## 二级标题
###### 六级标题

正文：**加粗**、__加粗__、*斜体*、~~删除线~~、`inline code`。

---

- [ ] 未完成任务
- [x] 已完成任务
  - 嵌套列表

1. 有序列表一
2. 有序列表二

> 引用内容
> **引用中的加粗**

```text
---
- [ ] 这里不是可勾选任务
**这里不是加粗**
```

紧接正文的分隔线
---

[示例链接](https://example.com)

转义：\*普通星号\*，实体：&amp;。
````

表格、数学公式和光标附近自动显示语法的 Full 模式不属于本期；未支持的结构应保留源码，不丢失内容。
