# Markdown 第二期：子任务 1 验收

本文记录公共编辑器按行展开的验收范围，覆盖工具栏精简、底部关闭保存及链接命中修复。子任务 2 的输入法、复杂鼠标选区和滚动稳定性仍需后续专项完善；本次已保留原生输入、撤销和鼠标选择期间的布局冻结。正式发布流程见 [RELEASING.md](RELEASING.md)。

## 本次行为

- 弹窗和底部共用 `MarkdownBlockEditor`，默认当前物理行显示 Markdown 源码，其余行保持排版；视觉自动换行仍属于同一源码行。
- 选区跨行时，涉及的各行展开；离开选区后恢复非当前行的排版。标题展开仍保留标题字号，行内加粗等样式继续可见。
- 两处工具栏均为 30×30 按钮，顺序为 `MD`、`H`、`B`、列表、任务，不显示正文 T；弹窗也不显示单独的预览按钮。MD 点击后完整显示源码，再次点击恢复按行展开。完整源码时按钮高亮；此选项仅保留在当前控件中，不新增设置或改变存储格式。
- 底部保存后仍显示完整阅读效果；编辑中复制得到原始 Markdown，阅读中复制得到可见文本。
- 底部右侧仅保留关闭按钮，关闭时自动保存，失败时保留草稿和编辑状态；Ctrl+S 保存、Esc 取消仍可用。日期弹窗的保存／取消行为不变。
- 编辑时非当前任务行显示的复选框只用于排版，点击后展开该行；阅读中仍可直接勾选并保存。已确认的阅读任务上下各 2px 间距保持不变。
- 本次代码块和图片行在编辑中始终显示源码，进入阅读后才显示完整效果；不增加块级编辑浮层或精确到单个行内标记的展开。

## 建议重点测试

在日期弹窗、底部常驻、底部今日分别粘贴下方样例：

````markdown
# 标题 **加粗**
正文 **加粗文字** 与 `inline code`
- [ ] 第一项任务
- [x] **已完成任务**
---
分隔线下方正文

```text
---
- [ ] 代码里的任务
```

最后一行
````

1. **切行**：用鼠标、上下方向键及 Home/End 在标题、正文、任务、`---` 之间移动。当前行能看到完整标记，离开后应恢复排版；光标不能落到错误行，源码不能被改写。
2. **编辑和撤销**：输入中文、英文、标点；增删 `**` 和 `---`；按 Enter 续写列表、删除换行合并段落，再 Ctrl+Z/Ctrl+Y。检查文字和任务状态均保留。
3. **选择**：跨标题／任务／分隔线拖选，Shift+方向键选择，Ctrl+A 后复制／替换／撤销。编辑复制应包含原始 `#`、`**`、`[ ]` 等标记。
4. **切换**：反复点 MD；正文、选区和撤销历史应保留。检查弹窗与底部工具栏顺序一致，且没有 T 或弹窗预览按钮。点击编辑中的任务框应展开源码，阅读中的任务框仍直接勾选。
5. **关闭保存／取消**：常驻与今日底部编辑后点击右侧关闭按钮，重新打开或重启后内容应保留；清空今日后关闭，应恢复常驻单栏。底部 Ctrl+S 保存、Esc 取消；日期弹窗保存／取消；编辑今日弹窗时观察底部实时预览，取消后应恢复保存内容，常驻草稿应保留。
6. **布局**：浅色／深色、窄底部、长行自动换行；按钮均保持正方形。代码块、图片编辑时显示源码，保存回到底部阅读时正确渲染；阅读任务间距仍为上下各 2px。
7. **链接命中**：底部保存 `[2026 鉴赏家新品节](https://act.steamchina.com/2026showcase)`，分别不加后缀、后接空格、前后接正文。阅读时仅链接文字显示手形光标和网址提示，并能点击打开；行尾空白不触发链接。再缩窄待办使长链接文字换行、滚动到文档底部，检查各行文字和右侧空白的行为一致。

鼠标精确落点、连续中文输入法组合、长文滚动和快速拖选请记录实际问题，作为子任务 2 的输入。当前按物理行展开会增加行宽，窄区域可能重新换行。

## 本地验证

使用仓库 SDK 8.0.425：

```powershell
dotnet run --project tests/ScrewCalendar.Tests/ScrewCalendar.Tests.csproj -c Release --no-restore --disable-build-servers
dotnet format ScrewCalendar.sln --verify-no-changes --no-restore --verbosity minimal
dotnet publish ScrewCalendar.csproj -c Release --no-restore --disable-build-servers -o artifacts/markdown-phase2-task1-publish
```

原生 WPF 回归覆盖按行视觉替换、标题字号、源码字符位置、跨行选区、鼠标松开前冻结、完整源码回退、阅读切换、复制、撤销、任务防误勾和两处共用工具栏。设置 `SCREW_MARKDOWN_QA_DIR` 可输出原生渲染截图。自动检查不能代替真实中文输入法和鼠标手感验证。
